# 学院事务咨询助手 · 使用说明

> 版本：2025-10　|　适用对象：本院大二至大四本科生　|　部署形态：静态单页问答（移动端优先）

## 一、适用范围（能答什么）
- 补考／缓考／重修／成绩复核的办理流程、材料、时限；
- 国家奖学金、国家励志奖学金、国家助学金、校内奖学金的条件、金额、兼得规则、评审时间；
- 宿舍报修（渠道、响应时限、人为损坏赔偿、投诉）；
- 教室多媒体设备报修（渠道、响应时限）。

## 二、不适用范围（不答什么）
- 资料未收录的问题（如交换生学分认定、校园卡补办）——原样提示"资料未收录"并给替代路径；
- 医疗、心理、法律、投资理财建议——说明能力边界并转介；
- 涉及金额审批、处分认定、学籍异动个案、代办文书——转人工（学院教学办公室／教务处）。

## 三、回答格式
每次回答固定三段式：
- 【结论】一句话直接回答；
- 【依据】文件名 ＋ 条款号 ＋ 原文关键句；
- 【下一步】办理入口／部门／联系电话。

## 五、如何更新语料
1. 修改 `agent/kb.json` 中的 `clauses` 与 `intents`（条目含 文件名／条款号／原文／关键词）；
2. 如正式文件更新，同步替换 `01_输出/语料库/` 对应文件，并在 `语料治理记录.md` 的版本表登记；
3. 废止文件一律移入 `01_输出/归档/`，不得保留在语料库；
4. 重新生成 `index.html` 并发布，保持链接可用。
